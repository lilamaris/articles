## 문제

0보다 크거나 같은 정수 N이 주어진다. 이때, N!을 출력하는 프로그램을 작성하시오.

## 입력

첫째 줄에 정수 N(0 ≤ N ≤ 20)이 주어진다.

## 출력

첫째 줄에 N!을 출력한다.

---

## 내 구현

```cpp
#include <iostream>
#define IO std::cin.tie(NULL), std::ios_base::sync_with_stdio(false)

long int fact(long int i) {
  if (i == 0)
    return 1;
  return i * fact(i - 1);
}

void solve() {
  int n;
  std::cin >> n;
  std::cout << fact(n);
}

int main() {
  IO;
  solve();
  return 0;
}
```
